# LaTeX for Research Papers

Course notes, published at https://deependujha.github.io/learning_latex/

- Notes live in [`src/`](src/); page order is set in [`src/SUMMARY.md`](src/SUMMARY.md).
- A compilable example paper is in [`example-paper/`](example-paper/).

Preview locally:

```bash
brew install mdbook
mdbook serve --open
```

Every push to `main` rebuilds and deploys the site via GitHub Actions.
